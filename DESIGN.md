# Squadron — Design

Source: the "Cuivre" (copper) page of the Claude Design canvas "Squadron — 10 directions" (screens C1 to C25), then whatever the app has shipped since. A single dark theme, warm brown and copper. The values live in CSS variables in `src/app.css`: that file is authoritative, this document says what they are for. Translatable interface (`src/lib/i18n`, `en` as the base + `fr`): every new string has both keys.

## Rules

Reread before any mockup, artifact, html block or style change.

- Only `app.css` tokens. A hard-coded color is allowed only if it appears in "Hard-coded exceptions" below; `scripts/design.test.ts` checks it.
- Copper (`--accent`, `--wait-*`, `--option*`) flags what is waiting for the user: permission, question, plan, badge. Never for an ordinary action.
- Main button: light, `--text` on `--ink`, 700 (`.btn-primary`). Not copper.
- `--background*` is the blue of background tasks, not a surface background. Ink on copper is `--accent-ink`.
- Radii: 6px for cards, 8px for dialogs and for conversation cards with a tone bar (PullCard, FileCard, LinkCard), 4px for buttons and fields.
- Outlines as `box-shadow: inset 0 0 0 1px …`, not `border`, except zone separators.
- Start from the CSS of the closest existing component (file named in "Components") instead of inventing. Reuse `StatusIcon`, `ModeIcon`, `Icon`, `Avatar`, `SidePanel`, `Dialog`, `Confirm`, `Select` rather than redrawing them.
- Use the `app.css` classes (`.btn*`, `.field`, `.option-*`, `.effect-*`, `.sr-only`) without redefining them.

## Mockups and artifacts

- **```html block in the conversation**: rendered in an iframe that receives the app's `:root` and `@font-face` (`Markdown.svelte`, `themeCss`). The tokens and DM Sans / DM Mono are there; the classes (`.btn`, `.field`…) are not: copy their rules from `app.css`. Background `--bg-main`, 13.5px/1.5. Its CSP only lets through inline styles and images and fonts from the app or `data:`: no network, no script.
- **Artifact** (`$SQUADRON_ARTIFACTS`, `artifact://` iframe): `<link rel="stylesheet" href="/__squadron/theme.css">` in the `<head>` gives all of `app.css` (tokens, classes, keyframes) and DM Sans / DM Mono, served by `artifacts.rs`. Do not copy the tokens by hand. Page background `--bg-app` by default, put `--bg-main` on the mocked-up area.
- Mock up at real size: widths from "Layout", conversation at 740px.
- Several variants: stack them on the same page, the current state first, each titled, same data, at its real width.
- Interactive mockup: its controls work (segments, switches, menus, fields) thanks to a small script in the artifact. An html block has no script: switch to an artifact as soon as interaction is needed.
- Mockup strings in English (the interface's base language).

## Typography

- **DM Sans** (`--sans`) for text, **DM Mono** (`--mono`) for code, paths, commands, costs and counters. Fonts are bundled (`@fontsource`), no Google Fonts.
- Base size 13.5px.
- Scale: 11 (captions, uppercase column headers), 11.5 (mono metadata, badges), 12 (subtitles, info), 12.5 (states, summaries, help, the most common), 13 (error text, menus), 13.5 (base), 14 (panel title), 15 (agent title, card title), 16 (Confirm and Settings title), 18 (dialog title), 22 (Kanban / Overview / PRs page title), 24 (empty states).
- Weights: 500 (secondary buttons), 600 (titles, names), 700 (main buttons, dialog and page titles, uppercase).
- Uppercase: 11px 700, `letter-spacing: 0.08em`, `--text-muted` or `--text-dim`.
- Line height: 1.5 (bubbles, help), 1.6 (prose), 1.65 (agent Markdown), fixed 20px for code and diff lines.
- "SQUADRON" mark: 12px, 700, uppercase, `letter-spacing: 0.12em`, preceded by a 14px copper triangle.

## Shapes and spacing

- Radii: 2px (bars, small dots), 3px (inline code, badges, chips), 4px (buttons, fields, rows), 6px (cards, blocks, menus), 8px (dialogs, Kanban columns, PullCard, FileCard, LinkCard), 50 % (dots), 999px (state pills).
- Spacing: 4, 6, 8, 10, 12, 14, 16, 18, 20, 24, 32px.
- Shadows: menus `0 14px 36px rgba(0,0,0,0.5)` + outline `0 0 0 1px --border-strong`, dialogs `0 30px 80px rgba(0,0,0,0.6)`, sliding panel `-18px 0 40px rgba(0,0,0,0.45)`, selected waiting agent `0 8px 24px rgba(201,105,58,0.18)`.
- Tone bar: 3px on the left of a card, state or type color (PullCard, FileCard, unread finished agent). 2px stripe for AdvisorCard and the own-comment thread.

## Layout

- Window without system decorations, minimum width 1000px.
- **Header** 54px, `--bg-app`, `1fr auto 1fr` grid, bottom line `--border`.
- **Agent list** 304px by default, adjustable from 240 to 560px.
- **Main area** `--bg-main`: agent header (60px min), optional info panel, conversation, composer, 26px status bar.
- **Conversation**: centered column `--conversation-width` (740px, adjustable), padding 20px, 14px between blocks. Marker column 40px `--bg-rail`.
- **Right panels** (`SidePanel`): 420px min. Default widths: diff 680 (side by side 1120), editor 780, terminal, sub-agents, artifacts 680. Modes: sliding, side by side, bottom, full screen, window.
- **Pages** (Kanban, Overview, PRs): header padding 24px 32px 16px, title 22px 700 with project square.

## Motion
Working ring: 1.4s linear rotation. Background task: 6s. Streaming cursor: 1s blink. Tab: `pulse` 2s or `snake` 2.4s, `ring` 2.4s. Unfolding a card or a form: slides down, the conversation scrolls just enough to show it. Everything stops under `prefers-reduced-motion`.

## Accessibility
Real `button`, `a`, `input` and `label`. `aria-label` on every icon button. Visible keyboard focus: 2px `--accent-soft` ring, offset by 2px. Waiting cards are labeled `section`s, errors are `role="alert"`, tabs are `role="tab"` with `aria-selected`.
